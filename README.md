🎵 Spotify Dashboard – Data Visualization Project
This project is a Spotify Dashboard designed to visualize key music streaming metrics, artist performance, and song popularity using interactive charts and tables.

📊 Overview
The dashboard provides insights into:

Artist Performance: Average hits, popularity trends, and streaming metrics.
Song Analytics: Track performance, duration, release dates, and album types.
Trending Data: Real-time and historical data visualizations for top artists and songs.

🧩 Features
Interactive Visualizations: Charts and graphs to explore music data dynamically.
Artist & Song Breakdown: Detailed views for top artists like Taylor Swift, Lady Gaga, Billie Eilish, and more.
Popularity Metrics: Average and max popularity scores per album/single.
Release & Duration Analysis: Insights into how release dates and song length affect streaming performance.
